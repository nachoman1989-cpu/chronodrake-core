# ChronoDrake Core

ChronoDrake is an AI Continuity Operating System designed to provide deterministic, offline-first project intelligence for AI-assisted development.

## Goals

- AI project continuity
- Deterministic context generation
- Offline-first architecture
- Knowledge graph analysis
- Project evolution tracking
- AI handoff generation

## Features

- Technology detection
- Incremental scanning
- Dependency intelligence
- Knowledge graph engine
- AI context generation
- SQLite persistence
- Timeline tracking
- Impact analysis

## Stack

- Rust
- SQLite
- Tokio
- Serde
- Tracing

## Philosophy

No cloud.  
No telemetry.  
No external AI APIs.  
Fully local-first.
